# OpenStudio

A free Android photo editor designed for powerful editing, privacy, and transparent AI features.

## Core editing
- Open photos and export edited copies
- Brightness, contrast, saturation, warmth and auto colour correction
- Rotate, flip, crop and blur effects
- Background correction and portrait skin-tone correction
- Non-destructive editing where practical

## Advanced editing roadmap
- AI-assisted background removal and subject selection
- Spot/healing removal for blemishes and unwanted small objects
- Auto sky enhancement/replacement
- RAW photo import and editing (format/device dependent)
- AI-assisted edits with a clear preview and undo
- Optional cloud-assisted editing for tasks that need online AI
- Local/offline editing for core tools; cloud processing must be opt-in and clearly explained

## Privacy and cost principles
- No mandatory account or subscription for basic editing
- Core adjustments should work offline
- Never upload a photo to cloud AI without the user's explicit action
- Clearly label which tools need internet and whether they use a server
- Keep original photos intact and save edits as a separate copy by default

## Project status
This is an early development build. Features listed as roadmap items are not yet confirmed implemented. The project must pass automated build checks and practical device testing before an APK is described as ready.
